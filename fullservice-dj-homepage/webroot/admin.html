Firmendaten (Briefkopf)

Empfohlen: PNG oder SVG mit transparentem Hintergrund, mindestens 400×400 Px (quadratisch oder quer, je nach Logo) – wird im Briefkopf auf max. 48px Höhe verkleinert, größer schadet also nicht.

Automatische Fahrtstrecke

Berechnet im Rider auf Knopfdruck die Autostrecke von deiner Firmenadresse (Firmendaten) zur Location, über OpenRouteService (EU-Anbieter, kostenloser API-Schlüssel). Ergebnis bleibt danach ein ganz normales, frei überschreibbares Eingabefeld – ohne Schlüssel gibst du Kilometer/Fahrzeit wie bisher von Hand ein.

System

Website-Updates – Änderungen aus der Entwicklung live stellen, ohne FTP

So funktioniert's: Neue Versionen landen auf dem GitHub-Branch live. Der Server holt sie sich selbst – automatisch per Cronjob oder hier per Klick. Deine Daten (Datenbank, Uploads) bleiben unberührt, vor jedem Update wird gesichert.
Token: github.com → Settings → Developer settings → Fine-grained tokens → nur dieses Repository, nur „Contents: Read". Wird sicher in data/gespeichert und nie wieder angezeigt.

Datensicherung

Wichtig: Backups liegen auf demselben Server – lade dir regelmäßig eins per Klick herunter (externe Kopie).
