System

Website-Updates – Änderungen aus der Entwicklung live stellen, ohne FTP

So funktioniert's: Neue Versionen landen auf dem GitHub-Branch live. Der Server holt sie sich selbst – automatisch per Cronjob oder hier per Klick. Deine Daten (Datenbank, Uploads) bleiben unberührt, vor jedem Update wird gesichert.
Token: github.com → Settings → Developer settings → Fine-grained tokens → nur dieses Repository, nur „Contents: Read". Wird sicher in data/gespeichert und nie wieder angezeigt.
