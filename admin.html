📖 Events anlegen

1. Links auf ➕ Event klicken oder im Dashboard offenen Termin wählen
2. Optional eine Vorlage wählen (Kneipe, Karaoke, Quiz, Vermietung)
3. Datum + Titel ausfüllen (Pflicht)
4. Event-Art aus dem Dropdown wählen
5. 🤖 KI-Button generiert Text automatisch oder optimiert Stichpunkte
6. Foto hochladen – wird online gespeichert
7. Speichern – sofort online sichtbar
⭐ Highlight = prominent auf der Startseite unter Programmhighlights
📌 Nächstes Event = wird als featured Event ganz oben angezeigt
🔒 Vermietung = Gäste sehen „Geschlossene Gesellschaft"
🟢 Sonderöffnungstag = Event außerhalb Fr/Sa/Vorfeiertag

📖 Rückblicke

1. Dashboard zeigt vergangene Events als Vorschläge
2. Klicke ✓ Freigeben – Name & Datum werden übernommen
3. Schreibe einen kurzen Bericht oder nutze 🤖 KI
4. Lade bis zu 5 Fotos hoch (1 Haupt + 4 Extra)
5. 👁 = Sichtbarkeit auf der Website ein/aus

🕐 Öffnungszeiten & „Jetzt geöffnet"

Im Dashboard unter „Öffnungszeiten" Wochentage aktivieren und Uhrzeiten setzen.
Die Website zeigt automatisch 🟢 Jetzt geöffnet oder Geschlossen – öffnet Fr ab 19:00.
An Event-Tagen gelten die Doors-Zeiten statt regulärer Öffnungszeiten.

🔧 Ersteinrichtung Supabase

1. SQL Editor öffnen ↗
2. SQL unten kopieren und Run klicken
3. Meldung „already exists" ist OK – heißt es ist bereits eingerichtet
